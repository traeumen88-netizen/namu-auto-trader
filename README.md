# 나무증권(NH투자증권) 주식 자동매매 시스템 (Namuh PLUG)

NH투자증권의 공식 Open API 플랫폼인 **'나무 플러그(Namuh PLUG)'**를 기반으로 구축된 파이썬 주식 자동매매 시스템입니다.

---

## 📌 주요 특징

1. **공식 REST API 완전 연동**:
   - `nhplug` 공식 라이브러리 기반 안전한 토큰 발급 및 자동 갱신
   - 초당 호출 유량 제한(Rate Limit) 방어 로직 내장
2. **이중 환경(모의투자 / 실전투자) 지원**:
   - **모의투자**: `50001003032` (모의 예수금 5억 원으로 안전한 전략 사전 검증)
   - **실전투자**: `20201549311` (실제 주식 계좌)
3. **검증된 핵심 매매 전략 기본 탑재**:
   - **래리 윌리엄스 변동성 돌파 전략**: 시초가 + (전일 변동폭 × 0.5) 목표가 돌파 시 자동 시장가 매수
   - **스마트 리스크 관리 (손익절)**:
     - **손절(Stop-Loss)**: -2.0% 도달 시 전량 시장가 매도
     - **익절(Take-Profit)**: +4.0% 도달 시 전량 시장가 매도
   - **자금 관리**: 1종목당 1회 최대 매수금액 제한 (기본 100만 원)
   - **당일 중복 매수 방지**: 이미 매수한 종목은 당일 재매수하지 않음
4. **원클릭 배치 파일 지원**:
   - `실행_모의투자.bat` (더블클릭 즉시 가상 자금으로 안전 실행)
   - `실행_실전투자.bat` (안전 확인 프롬프트 후 실전 가동)

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (추천)
- **모의투자 테스트**: `실행_모의투자.bat` 파일을 더블클릭합니다.
- **실전투자 가동**: `실행_실전투자.bat` 파일을 더블클릭하고 안내에 따라 `Y`를 입력합니다.

### 방법 2. 콘솔/터미널 실행
```powershell
# 모의투자 모드 실행
python main_trader.py --mock

# 실전투자 모드 실행
python main_trader.py --live
```

## ⚙️ 설정 변경 방법 (`.env` 및 `config.py`)

### 1. 손익절 비율 및 1회 매수 한도 변경 (`.env`)
```ini
STOP_LOSS_RATE=-0.02         # -2.0% 도달 시 전량 손절
TAKE_PROFIT_RATE=0.04        # +4.0% 도달 시 전량 익절
MAX_INVEST_PER_STOCK=1000000 # 1종목당 최대 100만 원 매수
```

### 2. 감시 종목 유니버스 모드 설정 (`.env` 또는 `config.py`)
국내 주식 퀀트 명세서 v5.0 기준(거래대금 상위, 주도 섹터 분산)에 따라 유니버스를 자유롭게 선택할 수 있습니다.
`.env` 파일에 `UNIVERSE_MODE`를 지정하거나 기본 50선이 자동 적용됩니다:

```ini
# 감시 유니버스 모드 선택:
# top50    : 코스피/코스닥 핵심 주도주 50선 (기본값, 추천)
# top100   : KOSPI 200 / KOSDAQ 150 핵심 수급주 100선
# top20    : 초저지연 초고속 감시용 메가캡 20선
# default8 : 초기 안전 테스트용 8선
# custom   : config/custom_universe.json 사용자 정의 종목
UNIVERSE_MODE=top50
```
- **주요 섹터 균형 반영**: 반도체(삼전, 하이닉스, 한미반도체 등), 2차전지(LG엔솔, 에코프로비엠 등), 바이오(삼바, 셀트리온, 알테오젠 등), 방산(한화에어로, 현대로템 등), 전력설비/원전(HD현대일렉, 두산에너빌리티 등), 로봇/AI 등 시장 핵심 주도주 자동 감시.
- **초당 유량 제한 방어**: 50~100개 종목 감시 시에도 0.25초 스마트 패이싱 및 일봉/목표가 캐싱으로 나무증권 서버 차단(429) 없이 실시간 순환 감시합니다.

## ⚠️ 유의사항 및 리스크 고지
- 알고리즘 매매는 시장의 급격한 변동성에 따라 손실이 발생할 수 있습니다.
- **반드시 모의투자(`실행_모의투자.bat`)로 수일간 체결 및 손익절 흐름을 충분히 관찰하신 후 실전에 적용하시기 바랍니다.**
- 시스템 종료는 실행 창에서 언제든지 `Ctrl + C` 키를 누르면 안전하게 종료됩니다.
